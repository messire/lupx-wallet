# ADR-0014: UI kit v0.2 "Indigo Glass" как визуальная архитектура фронтенда

## Статус

Принято — 2026-09-13.

**Уточнение визуального эталона — 2026-09-14:** по прямой корректировке пользователя зафиксирован [UI kit v0.3](../../design/ui-kit.md) и [автономный экран Wallets](../../design/wallets.html). Сохранены палитра, типографика, назначение компонентов и общая архитектура v0.2. Убрано декоративное свечение, ослаблены границы и отражения. Точные изменения и границы переноса описаны в [пакете передачи](../../design/README.md). Эта запись не означает внедрение v0.3 в Angular: `docs/design/tokens.css` задаёт целевые параметры нового эталона, `frontend/src/styles.scss` остаётся источником фактических стилей приложения до отдельного переноса. Исторический текст ниже описывает принятие v0.2.

## Контекст

Проект вёл разработку фронтенда со светлой сине-белой темой (токены `--color-*`/`--radius-*` в `frontend/src/styles.scss`), заданной с самого начала проекта без отдельного согласования визуального направления.

Пользователь инициировал пересмотр визуального направления (чат «Варианты визуального оформления») и выбрал направление: cyberpunk-эстетика, меньше деталей, больше лёгкости, воздуха и прозрачности, без пузырей, сфер, орбит и перегруженных сцен.

Первая реализация (v0.1) была отклонена пользователем: почти чёрные непрозрачные панели и бирюзовые кнопки не передавали материалы и свет исходного референса. Пользователь приложил исходное изображение (`docs/design/assets/visual-reference.png`), и направление переработано непосредственно по нему — версия v0.2, рабочее название **Indigo Glass**: насыщенное индиго, лавандовое освещение, розовые отражения, полупрозрачное стекло с просвечиванием фона сцены.

Полная спецификация зафиксирована в `docs/design/ui-kit.md`, токены — в `docs/design/tokens.css`, визуальная витрина — `docs/design/preview.html`. 2026-09-13 пользователь после живого просмотра витрины в браузере явно утвердил параметры v0.2 без правок (палитра, типографика, геометрия, эффекты, компоненты) — см. `docs/PROGRESS.md`, раздел «UI kit: визуальное направление и компоненты».

Токены `--lw-*` уже перенесены в `frontend/src/styles.scss` как единственный источник цвета/радиуса; старые `--color-*`/`--radius-*` временно оставлены алиасами на `--lw-*`, чтобы существующие feature-компоненты сразу подхватили новую тему без немедленного переписывания. Полное применение UI kit по всем экранам ведётся отдельным, уже запущенным этапом (см. `docs/PROGRESS.md`, «ПЛАН: полное применение UI kit v0.2») — настоящий ADR фиксирует факт принятого решения о направлении, не дожидаясь завершения переноса всех экранов.

## Решение

Принять **UI kit v0.2 "Indigo Glass"** (`docs/design/ui-kit.md`) как единственную визуальную архитектуру Angular-фронтенда LupexWallet:

- Индиго-фон (`--lw-bg`) с широкими переходами света вместо прежней светлой сине-белой темы.
- Стеклянные панели с просвечиванием фона сцены (`--lw-glass`/`--lw-glass-strong`), один слой стекла без вложенных размытий.
- Лавандово-розовый градиент (`--lw-primary-fill`, `--lw-accent`/`--lw-accent-secondary`) для основного действия и выделенных элементов.
- Типографика на системном стеке `"Segoe UI", system-ui, -apple-system, sans-serif` (кириллица без загрузки внешних шрифтов).

`frontend/src/styles.scss` с токенами `--lw-*` — источник истины для цвета, радиуса, типографики и эффектов на фронтенде. Старые токены `--color-*`/`--radius-*` — временный alias-слой на период миграции: они существуют только пока feature-компоненты не перенесены на прямое использование `--lw-*` (целевое место — переиспользуемые компоненты в `frontend/src/app/shared/ui/` по `docs/design/ui-kit.md §5`), и будут удалены после того, как перенос всех экранов завершится (см. пункты «ПЛАН: полное применение UI kit v0.2» в `docs/PROGRESS.md`).

### Что не входит в это решение

По `docs/design/ui-kit.md §1 «Основание и границы»`:

- Изменение бизнес-логики, HTTP-клиентов, маршрутов и API — не затрагиваются.
- Добавление новых экранов, функций, ролей, регистрации, email-входа или реальных платежей — не входит; UI kit задаёт только оформление уже существующих сценариев.
- Login содержит только пароль приложения; «Перевод» остаётся учётом перемещения между кошельками, не отправкой банковского платежа.

## Последствия

- Требуется точечная проверка контраста текста на полупрозрачных стеклянных поверхностях по месту, на реальном фоне каждого экрана после смешивания прозрачности — наличие токенов само по себе не гарантирует соответствие целевым порогам контраста (4.5:1 для обычного текста, 3:1 для границ управления и focus), как явно указано в `docs/design/ui-kit.md §3`.
- До завершения переноса всех feature-компонентов в `frontend/src/app/shared/ui/` в кодовой базе временно сосуществуют два слоя токенов: `--lw-*` (источник истины) и `--color-*`/`--radius-*` (alias на `--lw-*`). Это осознанный временный компромисс ради непрерывности работы существующих экранов, а не целевая архитектура — alias-слой подлежит удалению по завершении миграции.
- Дальнейшие визуальные изменения (новая версия направления, отклонение от согласованных параметров v0.2) требуют либо новой итерации согласования с пользователем, либо отдельного ADR, заменяющего данный.
