# Версионирование

Версия `X.Y.Z` ([SemVer](https://semver.org)). Релиз поднимает самую старшую часть из подходящих к изменениям с прошлого релиза:

- **Z (patch)** — только исправления: без новых функций, без изменений контракта API (`docs/api/openapi.yaml`) и без миграций схемы БД, меняющих формат данных.
- **Y (minor)** — новая функция или раздел. Пока версия 0.x, сюда же любое несовместимое изменение: контракт API, схема БД, поведение по умолчанию.
- **X (major)** — 1.0.0 ставится, когда владелец признает продукт стабильным. После этого X растёт только при несовместимых изменениях, а новые функции идут в Y.

Изменения копятся под `## [Не выпущено]` в `CHANGELOG.md`; релиз переименовывает заголовок в номер версии с датой.
