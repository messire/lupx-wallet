# ADR-0009: Визуальная архитектура фронтенда — UI kit v0.3

## Статус

Принято — 2026-09-13 (v0.2), уточнено 2026-09-14 (v0.3). Пересобрано 2026-09-30.

**Состояние реализации:** общие токены и компоненты v0.3 — во всём приложении; перепланировка экранов под макеты v0.3 выполнена для Кошельков (включая форму), Операций, Переводов, Истории баланса и Курсов валют. Отчёт, Справочники, Аудит и Login остаются на общих токенах без перепланировки.

## Контекст

Фронтенд начинался со светлой сине-белой темы, заданной без согласования визуального направления. Пользователь инициировал пересмотр и выбрал направление: cyberpunk-эстетика, меньше деталей, больше воздуха и прозрачности, без пузырей, сфер и перегруженных сцен.

- **v0.1** отклонена: почти чёрные непрозрачные панели и бирюзовые кнопки не передавали материалы и свет референса.
- **v0.2 «Indigo Glass»** переработана по изображению пользователя (`docs/design/assets/visual-reference.png`): насыщенное индиго, лавандовое освещение, розовые отражения, полупрозрачное стекло. Утверждена 2026-09-13 после живого просмотра витрины.
- **v0.3** — уточнение по прямой корректировке пользователя 2026-09-14: убрано декоративное свечение, ослаблены границы и отражения; палитра, типографика и назначение компонентов сохранены. Эталон — [ui-kit.md](../../design/ui-kit.md), автономные экраны в `docs/design/`.

## Решение

1. **UI kit v0.3** (`docs/design/ui-kit.md`, токены `docs/design/tokens.css`) — единственная визуальная архитектура Angular-фронтенда.
2. `frontend/src/styles.scss` с токенами `--lw-*` — источник истины для цвета, радиуса, типографики и эффектов в приложении. Прежние токены `--color-*`/`--radius-*` удалены.
3. Переиспользуемые компоненты — в `frontend/src/app/shared/ui/` (Button, Field, Checkbox, Radio, Badge, Card, Tabs, Dialog, EmptyState, LoadingState, ErrorState, Skeleton, Toast): standalone, OnPush, только `var(--lw-*)`, без знания о доменных моделях.
4. Индиго-фон с широкими переходами света; стеклянные панели с просвечиванием фона, один слой стекла без вложенных размытий; лавандово-розовый градиент для основного действия; системный стек шрифтов (`"Segoe UI", system-ui, -apple-system, sans-serif`) без внешних загрузок.
5. Навигация — sidebar 224px от 1100px, ниже — кнопка «Меню» с выпадающей панелью.

### Что не входит

Изменение бизнес-логики, HTTP-клиентов, маршрутов и API; новые экраны, роли, регистрация, email-вход, реальные платежи. Login содержит только пароль приложения; «Перевод» — учёт перемещения между кошельками.

## Последствия

- Контраст текста на полупрозрачных поверхностях проверяется по месту на реальном фоне каждого экрана (4.5:1 для текста, 3:1 для границ и focus); наличие токенов само по себе этого не гарантирует.
- Дальнейшие визуальные изменения требуют либо новой итерации согласования с пользователем, либо изменения этого ADR.
- Классы багов, связанные с рендерингом (`<dialog>` без `[open]`, `box-sizing`), не ловятся jsdom-тестами и проверяются только в реальном браузере — см. `docs/PROGRESS.md`.

## Отклонённые варианты

- **v0.1** — не соответствовала референсу.
- **Сохранение alias-слоя `--color-*`/`--radius-*`** — был временным на период миграции экранов, удалён.
- **Новый набор SVG-иконок и «контекстная» подпись в topbar из макета** — не перенесены: оформление без источника данных.
