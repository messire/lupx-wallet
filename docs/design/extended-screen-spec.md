# UI kit v0.3 — переводы, история баланса, курсы валют

Дата: 2026-09-15. Статус: три автономных экранных макета для оценки и последующего переноса. Отдельное утверждение этих экранов пользователем ещё не получено. Изменения находятся только в документации.

## Открыть

- [Переводы](transfers.html): фильтр, список, форма создания, действия и подтверждение удаления.
- [История баланса](balance-history.html): выбор кошелька, баланс на дату, история за период.
- [Курсы валют](exchange-rates.html): последние значения, время обновления, обновление и недоступный источник.

Запуск — по [README](README.md). Все экраны используют `tokens.css`, `wallets.css`, `screens.css` и `select.css`. Дополнительная компоновка находится в `extended-screens.css`. Палитра, мягкие поверхности, отсутствие glow и отступ стрелок 16 px сохранены. Новых графиков, декоративных сцен или финансовых функций нет.

## Переводы

Заголовок и одно основное действие «Добавить перевод», ниже фильтр по кошельку. Таблица содержит дату, источник, получателя, сумму с валютой и «···». Фильтр учитывает обе стороны перевода. «Загрузить ещё» раскрывает продолжение списка без фиктивной нумерации страниц.

Форма — диалог до 560 px: источник → получатель → сумма → дата. Получатели ограничены той же валютой и исключают источник. При смене источника получатель сбрасывается. Долларовый образец показывает отсутствие совместимого получателя с объяснением; конвертация не предлагается.

Сумма положительная, передаётся строкой с десятичной точкой. В таблице используется запятая и группировка разрядов без округления. Комиссии нет: списание равно зачислению. Нижняя граница даты — более позднее начало учёта двух кошельков, верхняя — текущая дата. Для демонстрации текущая дата зафиксирована на 15.09.2026.

Ошибка отправки сохраняет ввод; при ожидании поля и повторная отправка заблокированы. Отмена/Escape изменённой формы открывает подтверждение. Удаление выполняется через «···» и отдельное подтверждение с обоими кошельками, суммой, датой и последствиями. Прошлую дату удалить нельзя. Редактирование перевода не добавлено: соответствующего API нет.

Создание подтверждается основным действием самой формы. Дополнительного обязательного шага подтверждения перед каждым созданием не вводится. Подтверждение удаления и защита от потери ввода — предложения UI-слоя для переноса, которые не меняют финансовые правила.

## История баланса

Выбор одного кошелька определяет валюту и начало учёта. Два независимых сценария:

| Сценарий | Ввод | Результат |
|---|---|---|
| Баланс на дату | Дата или пустое значение для текущего баланса | Дата результата, сумма, валюта; до начала учёта — 0 с пояснением |
| История за период | Обе даты, начало не позже окончания | Ежедневные балансы, период применённого запроса, «Загрузить ещё» |

При смене кошелька прежние результаты и даты очищаются, чтобы сумма другого кошелька не оставалась под новым названием. Неизвестный баланс при ошибке/загрузке обозначается «—», не нулём. У результата периода своя подпись: изменение полей до отправки не меняет подпись уже показанных данных.

При первом открытии макета заранее выбран EUR-кошелёк и показан пример результата, чтобы можно было оценить компоновку. Это демонстрационная стартовая конфигурация, не требование автоматически выбирать кошелёк в приложении. Состояние без выбора доступно внизу страницы. График не добавлен: текущий сценарий использует таблицу.

## Курсы валют

Одно действие «Обновить сейчас», время последнего успешного обновления и таблица «Валюта → Основная валюта → Курс». Подпись прямо объясняет направление: сколько единиц основной валюты стоит одна единица исходной. В образце основная валюта EUR; при переносе она берётся из реальных данных, а не задаётся константой.

| Состояние | Поведение |
|---|---|
| Первичная загрузка | Ожидание, неизвестное время «—» |
| Первичная ошибка | Сообщение и «Повторить» |
| Ни одного успешного обновления | «Ещё не было», пустой список и действие обновления |
| Обновление | Кнопка заблокирована; уже полученные строки остаются доступны |
| Источник недоступен, данные есть | Сохранены прежние курсы и время; явно сказано, что они последние известные |
| Источник недоступен, данных нет | Нет подставленных курсов; объяснение и возможность повторить позже |
| Успех | Подтверждение и новое время успешного обновления |

Ни поиска, ни ручного редактирования курса, ни выбора произвольной базовой валюты не добавлено. Курс остаётся строкой; длинные дроби не округляются.

## Демонстрационные границы

Все значения вымышлены, включая котировки и время обновления. Это не текущие рыночные курсы. Нет сетевых запросов, API, авторизации и постоянного хранения. Изменения переводов действуют только в памяти этой страницы и исчезают после обновления. Соседние макеты не синхронизируют балансы и не образуют сквозной финансовый расчёт.

В истории подготовлены записи 09–15.09.2026. Для другой даты после начала учёта показано честное сообщение об отсутствии образца; до начала учёта действует правило нулевого баланса. Реальная история и курсоры подгружаются существующим API при переносе; локальные массивы и «Загрузить ещё» в HTML иллюстрируют только поведение интерфейса.

В свёрнутой секции «Проверка макета» доступны обычное, пустое, загрузочное, ошибочное состояния и длинные значения. Дополнительно у истории — отсутствие выбора и дата до учёта, у курсов — оба варианта недоступности источника. Результат запроса/сохранения выбирается перед действием. «Повторить» в образце демонстрирует успешное восстановление.

## Проверка и снимки

Все три экрана проверены в браузере на 1440, 768 и 360 px: горизонтального переполнения документа нет. На мобильном таблица переводов имеет минимальную ширину и внутреннюю прокрутку, чтобы названия не дробились по буквам.

Проверены: исключение источника и другой валюты из получателей, отсутствие совместимого получателя, отрицательная сумма, граница даты обоих кошельков, сохранение длинной дроби, блокировка повторной отправки, создание/удаление в памяти, подтверждение отмены и ошибка сохранения с сохранением ввода. В истории — ноль до начала учёта, обратный диапазон, сброс результата и переход EUR → USD. В курсах — блокировка кнопки, сохранение четырёх строк и времени после ошибки, недоступность источника без прежних данных.
