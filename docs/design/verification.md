# Проверка UI kit v0.3

Дата: 2026-09-14. Объект проверки — автономные `wallets.html`, `wallet-form.html`, `operations.html` и `preview.html`, не Angular-приложение. Среда — браузер Codex, локальная выдача через `serve.mjs`.

## Выполнено

| Проверка | Результат |
|---|---|
| 1440 px | Полная desktop-компоновка: sidebar, баланс, три карточки в строку, таблица. Горизонтального переполнения документа нет. |
| 768 px | Меню по кнопке, две карточки в строке, третья переходит ниже. Переполнения документа нет. |

## Полная форма и Operations — расширение v0.3

| Проверка | Результат |
|---|---|
| 1440 / 768 / 360 px | Обе страницы проверены; ширина документа не превышает viewport. Таблица Operations прокручивается в своей области. Исправлено переполнение от скрытой подписи столбца действий. |
| Создание кошелька | Пустая отправка показывает ошибки названия и типа, фокус на названии. Выбор значения очищает ошибку. |
| Точность и ошибка сохранения | `1234567890.123456789` остаётся без изменения после ошибки; повторная отправка во время ожидания заблокирована. Успешное сохранение показывает локальное подтверждение. |
| Редактирование основного | Учёт в общей сумме включён и заблокирован; валюта только для чтения. |
| Справочники | Добавление USD выбирает валюту и обновляет суффикс. Повтор после ошибки загрузки разблокирует справочник и возвращает фокус на тип. |
| Отмена изменений | У изменённой формы кошелька и операции есть подтверждение; «Продолжить заполнение» сохраняет ввод. |
| Фильтры Operations | Расходы возвращают три строки; обратный диапазон дат показывает ошибку. «Загрузить ещё» увеличивает список с 6 до 8 строк. |
| Состояния Operations | Пустое, загрузка с `aria-busy`, ошибка и повтор проверены. Длинная сумма `+1 234 567 890,123456789 EUR` не округляется и не распирает документ на 360 px. |
| Правила действий | У части перевода нет отдельного изменения/удаления. У прошлой даты удаление недоступно. Сегодняшняя операция удаляется из макета после подтверждения. |
| Форма операции | Отрицательный расход, в том числе с пробелом перед минусом, отклоняется. Корректировка допускает отрицательное значение; Absolute меняет подпись поля на «Новый баланс». Проверены создание и повторное открытие на редактирование. |
| Ошибка операции | Значение сохраняется после ошибки; поля и повторная отправка блокируются при ожидании. Мобильный диалог помещается по ширине и прокручивается по высоте. |
| Меню на 360 px | Escape закрывает меню и возвращает фокус на кнопку. |
| Консоль | В проверенных вкладках ошибок JavaScript не обнаружено. |

## Границы проверки

- Масштаб браузера 200%, screen reader, другие браузеры и режимы reduced-transparency / forced-colors ещё не проверены. CSS-fallback предусмотрен, но это не доказательство прохождения проверки на всех платформах.
- Полный аудит контраста прозрачных поверхностей не выполнен. Сохранённые цвета и отдельные контрольные пары не заменяют измерение каждого состояния на реальном фоне.
- Макет не обращается к API. Создание, редактирование, выход и реальные финансовые операции здесь не выполняются. Эти сценарии нужно проверять отдельно при переносе в Angular.
- Растровый ориентир не позволяет гарантировать точные размеры и цвета. Для реализации используются общие токены и CSS; это техническая фиксация выбранного направления, а не заявление о побайтовом совпадении с генерацией.
- Новый HTML ещё не проходил отдельную пользовательскую приёмку. Проверки этой страницы не означают готовность приложения к релизу.
