# Журнал изменений

Версии по правилу [docs/conventions/versioning.md](docs/conventions/versioning.md): patch — только исправления, minor — новые функции (а пока 0.x, и несовместимые изменения), major с 1.0.0 — несовместимые изменения.

## [Не выпущено]
- Приложение можно установить на телефон из браузера (PWA): иконка на рабочем столе, запуск без адресной строки. Данные по-прежнему загружаются только при наличии сети.
- Исправлена ошибка 500 при обновлении курсов: HTTP-обработчик Frankfurter больше не освобождается после ротации.

## [0.4.0] — 2026-11-15
Финансовое планирование.
- Долги и кредиты: кредиторы, погашения, график платежей с генерацией равных платежей.
- Фонды: резервы на кошельках, свободные средства, дефицит обеспечения.
- Бюджеты: категории расходов, месячные лимиты, исполнение по историческому курсу.
- Плановые операции с повтором: пропуск, перенос, частичное исполнение.
- Отчёты: свободные средства, ближайшие платежи, сводка долгов, прогноз движения денег на 1–12 месяцев.

## [0.3.0] — 2026-11-14
- Мягкое удаление и восстановление операций и переводов, история кошелька.
- Доступные и активные валюты, курсы только из БД, фоновая дозагрузка истории курсов (Frankfurter v2).
- Заявленный баланс и системная корректирующая сумма вместо абсолютной корректировки.
- Единый стиль выпадающих списков и выбора даты, «+ добавить новый» в формах.
- ADR пересобраны по темам.

## [0.2.0] — 2026-09-14
- UI kit v0.2 и витрина компонентов.
- Выравнивание кнопок фильтров и быстрого добавления на пяти экранах.

## [0.1.0] — 2026-09-13
- Кошельки, справочники, операции и переводы, история баланса, курсы валют, аудит.
- Вход по паролю (JWT).
- Модульный монолит: ASP.NET Core, EF Core, PostgreSQL; Angular SPA.
- Выбор валюты из справочника ISO 4217 с поиском.
- Деплой на Railway + Vercel, отдельные docker-compose для backend и frontend.
- Юнит- и интеграционные тесты (Testcontainers).
